# Study and Tag Context

This context covers studies users create and the tags they use to organize and
filter them.

## Language

**Study tag**:
A tag associated with a study for organizing and filtering studies. Tag details
are visible according to the user's access to that tag.
_Avoid_: project tag

**Default study tag**:
An existing study tag selected as a user preference for automatic application
to studies that user creates.
_Avoid_: default project tag
